# Truffle Scoop 참가 신청 페이지

정적 사이트입니다. `index.html`을 브라우저로 열면 바로 보입니다. (폰트만 CDN에서 불러옵니다.)

```
index.html   페이지 구조와 문구
style.css    디자인
script.js    신청 폼 동작 + 설정(맨 위 CONFIG)
assets/      배경 사진, 제목, 일러스트, 트러플, 로고
apps-script.gs   신청 내용을 구글 스프레드시트로 받는 스크립트
```

## 신청 내용 받기 (Google 스프레드시트)

`script.js`의 `SUBMIT_URL`이 비어 있는 동안은 **데모 모드**입니다. 신청해도 그 브라우저에만 저장되고 운영자에게는 전달되지 않아요. 실제로 받으려면:

1. 새 구글 스프레드시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `apps-script.gs` 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 권한으로 실행: **나**
   - 액세스 권한: **모든 사용자**
4. 배포 후 나오는 웹 앱 URL을 `script.js`의 `CONFIG.SUBMIT_URL`에 넣습니다.
5. 사이트에서 테스트 신청을 하고, 시트에 `신청` 탭과 한 줄이 생겼는지 확인합니다.

코드를 고쳐 다시 배포할 때는 **배포 관리 → 수정 → 새 버전**으로 올려야 같은 URL에 반영됩니다.

## 자주 바꾸는 값 (`script.js` 맨 위 `CONFIG`)

| 값 | 설명 |
| --- | --- |
| `SUBMIT_URL` | 신청 내용을 받을 주소 |
| `PRICE` | 1인 입장료 (확인 화면의 합계 계산에 사용) |
| `MAX_GUESTS` | 한 번에 신청 가능한 최대 인원 |
| `CLOSED` | `true`로 바꾸면 신청 버튼이 "마감되었습니다"로 바뀜 (소진 시) |

## 배포

폴더 통째로 Netlify / Vercel / GitHub Pages 등 정적 호스팅에 올리면 됩니다.
